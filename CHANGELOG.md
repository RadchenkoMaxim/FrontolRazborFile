# История версий

## 1.5.0 - 2026-08-12

- поле больше не редактируется в огромном многострочном окне: обычные значения вводятся в одну строку, перечисления выбираются из списка, а 15 флагов товара показаны понятными флажками;
- добавлена массовая замена вида маркировки для выбранных групп, включая произвольные коды;
- перестроена панель фильтров: все элементы остаются в одной строке и больше не оставляют пустую полосу;
- код, наименование, цена, штрихкод и маркировка выровнены в одну строку и не прыгают при смене товара;
- главное и вспомогательные окна адаптированы для масштабов Windows 100%, 125%, 150% и 175%, добавлен режим PerMonitorV2;
- в сводке появилось явное объяснение, что считается ошибкой и предупреждением;
- в окне «О программе» оставлена одна понятная ссылка `maximumit25.ru`;
- улучшена безопасность сохранения: проверяется внешнее изменение файла, недопустимые для Windows-1251 символы больше не заменяются на `?` молча;
- поддержан UTF-16 BE, переданное пустое поле отличается от непереданного, а дубликаты кодов больше не теряются при сравнении;
- полные списки из 68 полей создаются лениво, поэтому пиковая память smoke-прогона на полном `base.txt` снижена примерно с 525 до 222 МБ.

## 1.4.1 - 2026-08-12

- в фильтре команд рядом с техническим кодом отображается понятное назначение из встроенного справочника;
- выпадающий список команд расширен, длинные подписи аккуратно сокращаются, полное описание доступно при наведении;
- заголовки сворачиваемых групп также показывают, что делает команда.
- исправлен выбор поля по отдельной ячейке: кнопка редактирования больше не остаётся ошибочно неактивной;
- действие переименовано в «Изменить выбранное поле (F2)», добавлены понятная иконка, подсказка и горячая клавиша `F2`.

## 1.4.0 - 2026-08-12

- интерфейс переведён на спокойную единую палитру: синий для основных данных, зелёный для маркировки, жёлтый для изменений и красный для ошибок;
- убраны лишние рамки и вертикальные линии таблиц, упрощены поверхности, группировки и разделитель панелей;
- системные шрифтовые символы заменены единообразными векторными XAML-иконками 16×16;
- колонка «Команда» скрывается по умолчанию, поскольку команда уже указана в заголовке группы; пользовательская настройка после миграции сохраняется;
- для обрезанных кода, названия, штрихкода и маркировки добавлены подсказки с полным значением;
- пустые значения отображаются приглушённым курсивом «не передано», при этом исходное значение остаётся пустым и корректно сохраняется;
- добавлен список десяти последних открытых файлов;
- добавлен переход к физической строке по `Ctrl+G`;
- добавлена сводная статистика: строки, товары, служебные данные, команды, ошибки, предупреждения, изменения и распределение маркировки;
- фильтр маркировки стал мультифильтром с поиском, счётчиками и выбором нескольких видов;
- изменённые строки получают отдельное жёлтое обозначение до сохранения.

## 1.3.0 - 2026-08-12

- строки сгруппированы в сворачиваемые разделы «Товары», «Служебные команды» и «Структура файла», внутри — по командам;
- добавлены совместные фильтры по тексту, разделу, команде, состоянию и виду маркировки с быстрым сбросом;
- поиск подсвечивает найденный текст в списке;
- закреплена карточка товара с кодом, наименованием, ценой, штрихкодом и видом маркировки;
- добавлены чередование фона, контекстные меню, копирование значения двойным щелчком и панель полного текста ячейки;
- колонки списка можно включать и выключать, их ширина и ширина левой панели сохраняются;
- основной список подстраивает колонки под доступную ширину и больше не требует горизонтальной прокрутки;
- добавлено редактирование значения поля и целой физической строки с немедленной повторной проверкой;
- добавлено атомарное сохранение в исходной кодировке и формате строк, при перезаписи создаётся резервная копия `.bak`;
- добавлены экспорт видимых строк в CSV и сравнение товаров с другим файлом;
- панель инструментов получила компактные системные иконки открытия, сохранения, экспорта, сравнения и справки;
- необработанные ошибки интерфейса перехватываются приложением и записываются в локальный журнал вместо запуска JIT-отладчика.

## 1.2.1 - 2026-08-12

- добавлен отбор товарных строк по виду номенклатуры/маркировки из поля 55;
- список фильтра содержит только реально найдененные в файле виды и показывает количество товаров каждого вида;
- код, наименование и вид маркировки вынесены в отдельные акцентные колонки и в карточку выбранного товара; поля № 1, 3 и 55 визуально выделены в таблице;
- главное окно приложения теперь сразу запускается развернутым на весь экран.

- добавлены динамические схемы для 19 видов маркетинговых мероприятий и 24 видов условий;
- добавлено поисковое окно «Команды и поля»;
- уточнены флаг «Наливаемый товар», тип и диапазон крепости, ссылка на раздел классификаторов;

- служебные smoke-тесты теперь завершаются без системных окон ошибок.

## 1.1.1 - 2026-08-11

- добавлена горячая клавиша `Ctrl+M` и команда в меню «Вид»;

## 1.1.0 - 2026-08-11

- добавлена ручная плоская иконка приложения без генеративной графики;

- добавлено скрытие пустых полей;
- добавлена индивидуальная настройка видимости полей для каждой команды с сохранением в профиле пользователя;
- список строк теперь показывает код и наименование товара;
- удалены длинные всплывающие подсказки, перекрывавшие интерфейс;
- добавлен отдельный многострочный инспектор выбранного поля;
- добавлены действия «Открыть исходный файл» и «Показать в папке»;
- оптимизирован вывод десятков тысяч строк: полный файл на 43 542 строки отображается заметно быстрее;
