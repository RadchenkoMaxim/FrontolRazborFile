# История версий

## 1.1.1 - 2026-08-11

- добавлена кнопка `◀/▶` для полного скрытия и разворачивания списка строк;
- добавлена горячая клавиша `Ctrl+M` и команда в меню «Вид»;
- сохранена возможность менять ширину списка перетаскиванием разделителя;
- большой блок расшифровки теперь появляется только для содержательных пояснений;
- значения «Не передано», «Значение передано» и «Пустое значение» больше не занимают отдельную панель;
- путь к текущему файлу сделан компактным и больше не растягивает панель инструментов;
- уточнена визуальная иерархия панели выбранного поля.

## 1.1.0 - 2026-08-11

- добавлен встроенный справочник 38 кодов типа номенклатуры/маркировки и связанных параметров;
- добавлены номер версии, окно «О программе», разработчик Maximum IT и ссылка `https://maximumit25.ru/nfr`;
- добавлена ручная плоская иконка приложения без генеративной графики;
- добавлен индикатор чтения и разбора больших файлов;
- добавлено скрытие пустых полей;
- добавлена индивидуальная настройка видимости полей для каждой команды с сохранением в профиле пользователя;
- список строк теперь показывает код и наименование товара;
- удалены длинные всплывающие подсказки, перекрывавшие интерфейс;
- добавлен отдельный многострочный инспектор выбранного поля;
- добавлены действия «Открыть исходный файл» и «Показать в папке»;
- оптимизирован вывод десятков тысяч строк: полный файл на 43 542 строки отображается заметно быстрее;
- добавлен self-contained дистрибутив Windows x64 со встроенным .NET 10 Desktop Runtime.

## 1.0.0 - 2026-08-11

- первая рабочая версия анализатора;
- разбор Windows-1251 и UTF-8;
- поддержка товарных команд, удаления штрихкодов и связей классификаторов;
- проверка 68 товарных полей.
